FILES
index.html — Homepage and featured products
products.html — Searchable/filterable product catalog
mpg.html — Working miles-per-gallon calculator
contact.html — Contact form that opens email app
styles.css — Responsive styling
script.js — Catalog, calculator, and contact behavior

MPG PSEUDOCODE (CORRECTED)
start
  input milesTraveled
  input gallonsOfGasUsed
  milesPerGallon = milesTraveled / gallonsOfGasUsed
  output milesPerGallon
stop

TEST
Open index.html in a browser. Click each menu link.
On mpg.html, enter 300 miles and 10 gallons: expect 30.00 MPG.
Try 0 gallons: expect validation error.
On products.html, test search and category filters.
On contact.html, the button opens an email application; it does NOT send or save a message.

IMPORTANT
Products and prices are sample data; there is no checkout.
The contact form contains placeholder recipient contact@example.com in script.js. Replace it with your own verified email address before publishing if you want messages sent to you.
GitHub Pages cannot run PHP or MySQL. This version is HTML/CSS/JavaScript only.

PUBLISH
Create a PUBLIC GitHub repository named smartshop-final-project.
Upload the 4 HTML files, styles.css, and script.js to the repository root.
Settings > Pages > Deploy from a branch > main > /(root) > Save.
Submit the LIVE Pages URL, not the repository URL.

PHOTOGRAPHIC IMAGES
This version replaces product emojis/illustrations with photographs loaded from images.unsplash.com. Internet access is required for images to display. Product images are illustrative stock photos and may not show exact products. Verify photo availability and suitability before submitting.
